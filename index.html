How I work with AIComo trabalho com IA

AI coding agents are part of my daily workflow. They help me move faster, and I stay responsible for everything that ships. Agentes de IA fazem parte do meu dia a dia. Eles me ajudam a ir mais rápido, e eu continuo responsável por tudo que vai para produção.

  • Plan and build with agentsPlanejar e construir com agentes

    I use Claude and GitHub Copilot to plan features, write code and review it. I break bigger projects into steps and orchestrate agents through them while I steer the design and decisions.Uso Claude e GitHub Copilot para planejar funcionalidades, escrever e revisar código. Divido projetos maiores em etapas e oriento os agentes em cada uma, enquanto eu decido o desenho e as escolhas. WordPress plugins · Linux desktop app (AppImage) · accessible themePlugins WordPress · app desktop para Linux (AppImage) · tema acessível

  • Test before it shipsTestar antes de publicar

    Every change runs on a test site first. Only when it works there does it go to production, so speed never comes at the cost of the sites people rely on.Toda mudança roda primeiro num site de teste. Só quando funciona lá ela vai para produção, para que a velocidade nunca custe a estabilidade dos sites que as pessoas usam.

  • Keep systems improvingMelhorar os sistemas continuamente

    I use AI to read server logs, track down bugs, tune performance and refactor older code, so the platforms keep getting faster and safer over time.Uso IA para ler logs do servidor, encontrar bugs, ajustar desempenho e refatorar código antigo, para que as plataformas fiquem mais rápidas e seguras com o tempo.
